# Safety and scope

The learning runner parses fixed synthetic log fixtures and writes local evidence. It has no action for arbitrary URLs, commands, targets, uploaded events or remote integrations. The example IP ranges and domains are reserved documentation values. Lesson text describes observations, potential explanations and defender decisions. The destructive activity, credential and privilege scenarios use inert event metadata.

Advanced lab setup requires an owned and isolated environment and an explicit operator choice. Use disposable VMs and accounts scoped to sample telemetry. Keep collector, indexer and dashboard services on a private network. Review provider and vendor terms before installing independent tools.

Contribute generated samples with fictional identifiers. Review benign alternatives and suppression impact. Report suspected vulnerabilities through the private process in [SECURITY.md](../SECURITY.md).
