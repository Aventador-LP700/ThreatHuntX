# 19 · HTTPS/DNS Command & Control

Explore repeated DNS lookups classified as high entropy for an uncommon destination domain.

**Track** Intermediate · 12 min · Network

**Prerequisites** Be comfortable reading timestamps and network sensor or waf projection fields.

## Investigate

**Attacker intent** Hidden command channels.

**Learning outcome** Check the DNS host, domain and timestamps, then compare process and egress telemetry for the same host.

1. Review the clean baseline. Network sensor or WAF projection supplies the exercise evidence.
2. Consider the hypothesis. Three distinct observations of high-entropy labels targeting a rare domain justify a DNS activity pivot.
3. Replay the positive fixture and inspect THX-19. Check the DNS host, domain and timestamps, then compare process and egress telemetry for the same host.
4. Compare the noisy fixture. CDNs, update networks and security agents can emit opaque DNS labels.

## Rule and evidence

Count at least 3 observation(s) per `domain` inside 180 seconds. Count distinct `observables.query_id` values.

| Field | Comparison | Value |
| --- | --- | --- |
| `action` | `eq` | `"dns_query"` |
| `observables.label_entropy_class` | `eq` | `"high"` |
| `observables.domain_popularity` | `eq` | `"rare"` |

Tuning guidance. Segment expected infrastructure, track observed domain age externally if available, and check process baselines.

## Contain and prevent

Preserve DNS and resolver logs, correlate endpoint process evidence and constrain egress if justified.

Use controlled resolvers, egress filtering and DNS analytics with reviewed allowlists.

## Knowledge check

- What is the follow-up pivot?

  - The wallpaper settings

<details>
<summary>Answer and rationale</summary>

Endpoint process and egress telemetry for the host. DNS alone gives network context, while endpoint evidence can identify the requester.

</details>

- Why review expected CDN behavior?
  - CDNs always use clear names
  - Legitimate services can use opaque labels

<details>
<summary>Answer and rationale</summary>

Legitimate services can use opaque labels. Opaque DNS alone can be noisy.

</details>
