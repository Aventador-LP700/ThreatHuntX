# 24 · Data staging

Triage an archive audit record when an unusual actor stages multiple sensitive files together.

**Track** Intermediate · 12 min · Linux

**Prerequisites** Be comfortable reading timestamps and linux audit projection fields.

## Investigate

1. Review the clean baseline. Linux audit projection supplies the exercise evidence.
2. Consider the hypothesis. A large archive of sensitive files written to a shared staging area should be compared with authorized workflows.
3. Replay the positive fixture and inspect THX-24. Review input classification, output location and actor, then pivot to transfer telemetry.
4. Compare the noisy fixture. An authorized support bundle or export can build a temporary archive.

## Rule and evidence

Count at least 1 observation(s) per `user` inside 300 seconds. Each distinct source record can count once.

| Field | Comparison | Value |
| --- | --- | --- |
| `action` | `eq` | `"archive_summary"` |
| `observables.input_class` | `eq` | `"sensitive"` |
| `observables.destination_class` | `eq` | `"shared_staging"` |
| `observables.input_count` | `gte` | `20` |

Tuning guidance. Correlate staging paths and approval metadata. Use baselines for file count and data class.

## Contain and prevent

Identify who owns the archive, confirm its destination and preserve evidence before deleting any temporary copies.

Limit staging access, use DLP and monitor outbound transfers from systems with sensitive datasets.

## Knowledge check

- What scopes potential data exposure?
  - Input class and staging destination
  - Only the archive filename suffix

<details>
<summary>Answer and rationale</summary>

Input class and staging destination. Data class and destination describe sensitivity and who could access it.

</details>

- Which follow-up distinguishes staging from export?
  - Another archive with the same extension
  - A corresponding transfer or delivery event

<details>
<summary>Answer and rationale</summary>

A corresponding transfer or delivery event. Transfer evidence confirms movement beyond the staging location.

</details>

## Validation and mapping

Baseline and noisy fixture produce no alerts. The positive fixture produces an alert with linked evidence.

An archive observation does not show that a transfer occurred. No files are bundled or archived by the lab.
