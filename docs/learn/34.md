# 34 · Secrets in Git/Artifacts

Triage a secret-scanner finding based on its classification and artifact exposure.

**Track** Beginner · 8 min · CI/CD

**Prerequisites** Read the baseline and compare event fields. No external tools are required.

## Investigate

**Attacker intent** Leak sensitive credentials.

**Learning outcome** Read scanner rule, path and exposure. Preserve only redacted findings and check whether the artifact was distributed.

## Contain and prevent

Verify the finding privately, revoke or rotate a real credential if confirmed, and scope any access after disclosure.

Run secret scanning before release and use short-lived credentials or workload identity.

  - An actual secret value
