# 16 · RDP / SMB / WinRM abuse

Find repeated administrative sessions between a peer and multiple destinations outside a managed jump-host path.

**Track** Intermediate · 12 min · Windows

**Prerequisites** Be comfortable reading timestamps and windows security or sysmon projection fields.

## Investigate

1. Review the clean baseline. Windows security or Sysmon projection supplies the exercise evidence.
2. Consider the hypothesis. Three administrative sessions to distinct targets from a peer source within ten minutes warrant a lateral movement hunt.
3. Replay the positive fixture and inspect THX-16. Compare the service, source zone and distinct target IDs. Review authorization and process activity on both sides.
4. Compare the noisy fixture. An approved desktop-support activity can touch several systems within minutes.

## Rule and evidence

Count at least 3 observation(s) per `source_ip` inside 600 seconds. Count distinct `observables.target_id` values.

| Field | Comparison | Value |
| --- | --- | --- |
| `action` | `eq` | `"remote_session"` |
| `outcome` | `eq` | `"success"` |
| `observables.service` | `in` | `["rdp", "smb", "winrm"]` |
| `observables.peer_zone` | `eq` | `"workstations"` |
| `observables.admin_logon` | `eq` | `true` |

Tuning guidance. Maintain separate jump infrastructure and allowlist formally approved tools and accounts by destination class.

## Contain and prevent

Verify authorization out of band and scope the account and peer host. Terminate confirmed unauthorized sessions.

Require segmented management paths, MFA for remote access and monitored privileged accounts.
