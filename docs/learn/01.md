# 01 · Phishing

Review a suspicious email link through mail-gateway and URL inspection signals.

**Track** Beginner · 8 min · Identity

**Prerequisites** Read the baseline and compare event fields. No external tools are required.

## Investigate

1. Review the clean baseline. Mail gateway or attachment projection supplies the exercise evidence.
2. Consider the hypothesis. A credential-lure verdict and failed sender alignment on the same inspected link justify reviewing the message.
3. Replay the positive fixture and inspect THX-01. Check the recipient, sender alignment, URL verdict and destination domain. Keep the domain as evidence text.
4. Compare the noisy fixture. Legitimate forwarded mail can fail alignment. Use independent URL inspection before escalating.

## Rule and evidence

Count at least 1 observation(s) per `user` inside 300 seconds. Each distinct source record can count once.

| Field | Comparison | Value |
| --- | --- | --- |
| `action` | `eq` | `"url_inspection"` |
| `observables.sender_alignment` | `eq` | `"fail"` |
| `observables.url_category` | `eq` | `"credential_lure"` |

Tuning guidance. Scope exceptions to a known sender and forwarding flow. Review the redirect and expiration of any allowlist entry.

## Contain and prevent

Quarantine matching messages, review clicks and sign-ins, and reset sessions if the recipient entered credentials.

Enforce DMARC with SPF and DKIM, inspect URLs, and require phishing-resistant authentication.

## Knowledge check

- Which fields matter together?
  - URL verdict and sender alignment
  - Mailbox size and recipient display name

URL verdict and sender alignment. The detection combines a lure verdict with failed sender alignment.

  - The original email subject alone
  - Follow-up sign-in and session evidence

<details>

Follow-up sign-in and session evidence. A blocked message has different impact from subsequent account activity.

## Validation and mapping

Baseline and noisy fixture produce no alerts. The positive fixture produces an alert with linked evidence.

URL classification is supplied by the simulated gateway. The lab never contacts the destination.

Enterprise ATT&CK 20.1 · direct. The behavior in this lesson corresponds to this technique; the fixture models a defensive observation.
