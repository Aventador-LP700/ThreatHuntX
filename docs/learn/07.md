# 07 · HTML Smuggling

Compare attachment-inspection results for normal HTML and a sandbox-classified generated artifact.

**Track** Intermediate · 12 min · Windows

**Prerequisites** Be comfortable reading timestamps and mail gateway or attachment projection fields.

## Investigate

**Attacker intent** Payload via attachment.

**Learning outcome** Identify attachment type, sandbox trait and message ID. Correlate delivery and endpoint follow-on evidence.

1. Review the clean baseline. Mail gateway or attachment projection supplies the exercise evidence.
2. Consider the hypothesis. An HTML attachment that materializes an embedded file in sandbox telemetry warrants message triage.
3. Replay the positive fixture and inspect THX-07. Identify attachment type, sandbox trait and message ID. Correlate delivery and endpoint follow-on evidence.
4. Compare the noisy fixture. An internal export can embed a harmless downloadable report.

## Rule and evidence

Count at least 1 observation(s) per `user` inside 300 seconds. Each distinct source record can count once.

| Field | Comparison | Value |
| --- | --- | --- |
| `action` | `eq` | `"attachment_scan"` |
| `observables.file_ext` | `in` | `[".html", ".htm"]` |
| `observables.sandbox_trait` | `eq` | `"embedded_file_materialization"` |

## Contain and prevent

Quarantine matching messages, preserve sandbox metadata and review user interaction and downloaded-file events.

Apply HTML attachment controls, approved sandboxes and browser download policy.
