# 21 · Active Directory Enumeration

Separate expected directory inventory from repeated user enumeration by a workstation account.

**Track** Advanced · 15 min · AD

**Prerequisites** Know the basics of AD auditing and how to review authorization context.

## Investigate

**Attacker intent** Map users and trusts.

**Learning outcome** Compare actor, LDAP query class, query scope and client role. Check how often that actor normally queries the directory.

1. Review the clean baseline. Windows security or Sysmon projection supplies the exercise evidence.
2. Consider the hypothesis. A workstation actor issuing repeated directory-wide user-listing queries warrants a directory discovery hunt.
3. Replay the positive fixture and inspect THX-21. Compare actor, LDAP query class, query scope and client role. Check how often that actor normally queries the directory.
4. Compare the noisy fixture. Auditors, administrators and inventory jobs can enumerate users legitimately.

## Rule and evidence

Count at least 2 observation(s) per `user` inside 300 seconds. Each distinct source record can count once.

| Field | Comparison | Value |
| --- | --- | --- |
| `action` | `eq` | `"ldap_query_summary"` |
| `observables.query_class` | `eq` | `"user_listing"` |
| `observables.client_class` | `eq` | `"workstation"` |
| `observables.breadth_class` | `eq` | `"directory_wide"` |

Tuning guidance. Separate registered inventory jobs and narrow approvals by actor, source and expected scope.

## Contain and prevent

Scope the account, verify its authorization and examine accompanying authentication and access activity.

Audit directory queries for sensitive objects and reduce the reach of unmanaged directory clients.

## Knowledge check

- Which distinction is helpful?
  - Ordinary workstation versus managed inventory source
  - Long versus short host name

<details>
<summary>Answer and rationale</summary>

Ordinary workstation versus managed inventory source. Client role can distinguish unscheduled discovery from an approved inventory task.

</details>

- What checks scope?
  - An alert severity alone
  - The query class and breadth

<details>
<summary>Answer and rationale</summary>

The query class and breadth. Query scope determines why the event matters and how to investigate it.

</details>
