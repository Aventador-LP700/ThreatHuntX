# 06 · PowerShell Abuse

Investigate a PowerShell script-block observation with an unusual document-application parent.

**Track** Intermediate · 12 min · Windows

**Prerequisites** Be comfortable reading timestamps and windows security or sysmon projection fields.

## Investigate

**Attacker intent** Suspicious script execution.

**Learning outcome** Use event 4104, parent process and script classification, then pivot to process identity and document origin.

1. Review the clean baseline. Windows security or Sysmon projection supplies the exercise evidence.
2. Consider the hypothesis. An obfuscated PowerShell observation under an office parent warrants process-tree and document review.
3. Replay the positive fixture and inspect THX-06. Use event 4104, parent process and script classification, then pivot to process identity and document origin.
4. Compare the noisy fixture. Internal Office automation can invoke maintenance tooling with similar lineage.

## Rule and evidence

Count at least 1 observation(s) per `user` inside 300 seconds. Each distinct source record can count once.

| Field | Comparison | Value |
| --- | --- | --- |
| `event_id` | `eq` | `"4104"` |
| `process` | `in` | `["powershell.exe", "pwsh.exe"]` |
| `parent_process` | `in` | `["winword.exe", "excel.exe"]` |
| `observables.script_class` | `eq` | `"obfuscated"` |

Review the following event-level exclusions before changing the rule.

- `observables.approved_automation` eq `true`

Tuning guidance. Verify a specific signed workflow and execution identity before creating a bounded exception.

## Contain and prevent

Preserve script-block and process records, scope related executions and isolate if other evidence supports compromise.

Enable script block logging, AMSI integration and application control. Review Office child-process policy.

## Knowledge check

- Which event supplies script-block context?
  - 4104
  - 4624

<details>
<summary>Answer and rationale</summary>

4104. 4104 is a PowerShell script-block logging event, whereas 4624 denotes successful logon.

</details>

- What makes the lineage relevant?
  - The machine had a descriptive name
  - An office process launched the script interpreter

<details>
<summary>Answer and rationale</summary>

An office process launched the script interpreter. Parentage helps distinguish the unusual launch context from ordinary interactive administration.

</details>
