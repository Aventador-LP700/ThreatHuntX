# Role-based curricula

Each pathway starts with a lesson and progresses toward a decision or artifact that you can explain to another analyst. Use the learning report to record your progress.

| Pathway | Lessons | What to practise |
| --- | --- | --- |
| SOC L1 | [MFA fatigue](../learn/02.md), [Phishing](../learn/01.md), [Spraying](../learn/03.md), [Autoruns](../learn/09.md), [RMM](../learn/39.md) | Identify the actor and affected resource, write the evidence-backed triage disposition and escalation reason. |
| SOC L2 / Threat Hunter | [PowerShell](../learn/06.md), [Kerberoasting](../learn/13.md), [Remote services](../learn/16.md), [DNS](../learn/19.md), [AD](../learn/21.md), [AiTM](../learn/26.md) | Write a hypothesis, hunt across evidence sources and document plausible benign explanations. |
| Detection Engineer | [Spraying](../learn/03.md), [PowerShell](../learn/06.md), [Autoruns](../learn/09.md), [Tool tampering](../learn/18.md), [Ransomware-like activity](../learn/23.md), [Secret findings](../learn/34.md) | Compare fixture behavior, inspect fields and thresholds, and propose a narrow suppression with tests. |
| Penetration Tester to Purple Teamer | [WAF](../learn/04.md), [Privilege change](../learn/15.md), [Windows binaries](../learn/17.md), [File activity](../learn/23.md), [Metadata](../learn/37.md), [Drivers](../learn/38.md) | Translate inert observations into explicit hypotheses, telemetry requirements and observable response actions. |
| Cloud / DevSecOps | [IAM](../learn/20.md), [Dependencies](../learn/31.md), [CI tokens](../learn/32.md), [Workflows](../learn/33.md), [RBAC](../learn/35.md), [SaaS](../learn/40.md) | Tie grants or changes to actors, approval records and follow-on use. Keep a scoped evidence trail. |
