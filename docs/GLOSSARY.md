# Glossary

| Term | Meaning in ThreatHuntX |
| --- | --- |
| ATT&CK technique | An official MITRE behavior identifier, with rationale for each corresponding exercise. |
| Baseline | Bundled clean events illustrating an expected use case. |
| Correlation window | Time range in which qualifying evidence for the same group can contribute to a detection. |
| Detection | A selection and optional threshold that makes a defensive signal observable. |
| Evidence reference | Fixture path and record ID pointing to the exact observation underlying a replay. |
| Fixture | A fixed set of generated records for one scenario and expected outcome. |
| Noisy negative | A fixture with activity that should produce zero alerts despite apparent similarities to the positive case. |
| Playbook | Steps an analyst can use to scope, contain and validate recovery for an observation. |
| Scenario | Lesson, mapping, source assumptions, fixture and tests for a defensive hypothesis. |
| Suppression | An explicit exception to event selection for well-understood context. |
