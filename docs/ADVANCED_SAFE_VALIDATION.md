# Advanced validation scope

Use a disposable machine that you administer. Identify the owner, the approved data sources, the expected records, and the cleanup owner before beginning. Save a snapshot and establish the lab network boundary. Write a preview with the input files, expected decoder and rule IDs, and which service will receive the data. Start with the bundled replay or the offline vendor adapter exercise. [Vendor samples](VENDOR_SAMPLES.md)

An allowlist for a first validation can contain one named synthetic fixture, the bundled offline DNS capture, and a normal sign-in observation from a disposable account that you control. Review the inputs and record the operator's consent. Verify the expected source, timestamp and classifier. Preserve only sanitized evidence, stop the optional services, then restore or delete the disposable environment.

If a team uses an approved security exercise catalog such as Atomic Red Team outside this repository, have the operator independently review and allowlist a harmless observation with the owner. Keep the selected observation and manual preview in the team’s own authorization record. The documented ThreatHuntX exercises start from packaged evidence and measure the defender's interpretation, collection, and rules. [Safety and scope](SAFETY_AND_SCOPE.md)
