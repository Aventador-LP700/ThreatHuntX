# Roadmap

## Community alpha scope

- Community Lab with guided local replay and portfolio-safe exports.
- Forty scenario lessons and normalized detections, with dedicated browser checks for ten core lessons.
- Original Sigma specifications, Wazuh event-candidate examples and review-only KQL/SPL templates.
- Optional locally buildable static showcase.

## Planned research and verification

- Rehearse Wazuh manager, Windows Sysmon, Linux audit, Zeek, Suricata and Velociraptor integrations in disposable environments.
- Compare provider-native fields and documented sample joins across identity, cloud, GitHub and Kubernetes.
- Validate vendor query templates and correlation edge cases on approved installations.
- Run first-use exercises with independent learners and test Docker Desktop on Windows and macOS.
- Extend distinct-value correlation tests and measure build as well as runtime footprint on smaller hosts.
