# Security policy

The current `0.1.x` Community Lab line is in alpha and receives security fixes as time permits. Review supported versions before running older checkouts.

Report a vulnerability privately using [GitHub private vulnerability reporting](https://github.com/Aventador-LP700/ThreatHuntX/security/advisories/new) when enabled. If it is unavailable, contact the [maintainer](https://github.com/Aventador-LP700) privately for a disclosure channel. Share the affected revision, Docker and OS versions, a short description, and redacted reproduction evidence from a local installation. Keep real credentials, business logs and learner records out of reports.

The application assumes use on a trusted computer through its loopback interface. It has no public multi-user authentication. Report bugs affecting fixture integrity, arbitrary execution, local-to-remote access, privacy or dependency security. Send optional vendor product defects through the vendor’s disclosure channel. Coordinate publishing a confirmed vulnerability with the maintainer.
